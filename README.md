# Quickora

A polished, responsive quick-commerce grocery storefront built with Angular, TypeScript, HTML, and CSS. Product imagery uses lightweight illustrated emoji artwork with colored backdrops so the catalog remains reliable without third-party image services.

## Features

- Responsive home page with delivery location, delivery estimate, promotions, category browsing, and product catalog
- Search by product name and filter by category across 24 Indian grocery products
- Shared cart state with quantity controls, item removal, subtotal, savings, and localStorage persistence
- Demo coupons: `QUICK10` takes 10% off; `SAVE50` takes ₹50 off baskets of ₹299 or more
- Validated demo checkout for customer and delivery details with UPI, card, or cash selection
- Generated demo order confirmation; no real payment processing
- Sign-in modal UI and add-to-cart notifications

## Tech stack

Angular standalone component, Angular Signals, TypeScript, template-driven forms, and plain CSS.

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI (usually `http://localhost:4200`). To create a production build, run `npm run build`.
